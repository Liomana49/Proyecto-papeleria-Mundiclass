Planificación del Proyecto

Cronograma de Desarrollo (17 semanas)

Semana Actividades Entregables
1-2 Análisis de requisitos y diseño de la base de datos Esquema de BD, diagramas ER
3-4 Configuración del proyecto FastAPI y dependencias Estructura básica del proyecto
5-6 Implementación de modelos y esquemas Pydantic Modelos SQLAlchemy, esquemas de validación
7-8 Desarrollo de CRUD para usuarios Router de usuarios, endpoints básicos
9-10 Desarrollo de CRUD para productos y categorías Routers de productos y categorías
11-12 Desarrollo de CRUD para clientes y compras Routers de clientes y compras
13-14 Implementación de historial de eliminaciones Router de historial, lógica de auditoría
15-16 Integración de subida de imágenes con Supabase Funcionalidad de imágenes, configuración Supabase
17 Pruebas finales, documentación y despliegue Documentación completa, aplicación desplegada

Mapa de Endpoints

Usuarios (/usuarios)

  • GET /usuarios - Listar usuarios
  • GET /usuarios/{usuario_id} - Obtener usuario específico
  • POST /usuarios - Crear usuario
  • PUT /usuarios/{usuario_id} - Actualizar usuario
  • DELETE /usuarios/{usuario_id} - Eliminar usuario
  • GET /usuarios/historial/eliminados - Historial de usuarios eliminados

Productos (/productos)

  • GET /productos - Listar productos
  • POST /productos - Crear producto
  • PUT /productos/{producto_id} - Actualizar producto
  • DELETE /productos/{producto_id} - Eliminar producto
  • POST /productos/{producto_id}/imagen - Subir imagen de producto
  • GET /productos/historial/eliminados - Historial de productos eliminados

Clientes (/clientes)

  • GET /clientes - Listar clientes
  • GET /clientes/{cliente_id} - Obtener cliente específico
  • POST /clientes - Crear cliente
  • PUT /clientes/{cliente_id} - Actualizar cliente
  • DELETE /clientes/{cliente_id} - Eliminar cliente
  • GET /clientes/historial/eliminados - Historial de clientes eliminados

Compras (/compras)

  • GET /compras - Listar compras
  • POST /compras - Crear compra
  • DELETE /compras/{compra_id} - Eliminar compra
  • GET /compras/historial/eliminados - Historial de compras eliminadas

Categorías (/categorias)

  • GET /categorias - Listar categorías
  • POST /categorias - Crear categoría
  • PUT /categorias/{categoria_id} - Actualizar categoría
  • DELETE /categorias/{categoria_id} - Eliminar categoría
  • POST /categorias/{categoria_id}/imagen - Subir imagen de categoría
  • GET /categorias/historial/eliminados - Historial de categorías eliminadas

Historial (/historial)

  • GET /historial/eliminados - Listar todos los elementos eliminados

Health Check

  • GET / - Estado general de la API
  • GET /health - Verificación de salud del servicio
