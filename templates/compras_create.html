Crear Nueva Compra

Esta sección permite crear nuevas compras en el sistema de inventario y ventas.

Funcionalidades

  • Crear nuevas compras

Campos de Compra

  • Cliente ID: ID del cliente que realizó la compra
  • Producto ID: ID del producto comprado
  • Cantidad: Cantidad de productos comprados
  • Precio Unitario Aplicado: Precio por unidad aplicado en la compra

Ejemplo de Uso

Para crear una nueva compra, envía una solicitud POST a /compras con los datos requeridos.

Acciones

  • Listar Compras
  • Actualizar Compra
  • Eliminar Compra
