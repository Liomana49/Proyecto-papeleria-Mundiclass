Actualizar Historial

Esta sección permite actualizar registros de historial existentes en el sistema de inventario y ventas.

Funcionalidades

  • Actualizar registros de historial existentes

Campos de Historial

  • ID: Identificador único del registro de historial
  • Entidad: Nombre de la entidad afectada
  • Entidad ID: ID de la entidad afectada
  • Acción: Acción realizada (create, update, delete)
  • Valores Antiguos: Valores antes del cambio
  • Valores Nuevos: Valores después del cambio
  • Usuario ID: ID del usuario que realizó la acción

Ejemplo de Uso

Para actualizar un registro de historial, envía una solicitud PUT a /historial/{id} con los datos requeridos.

Acciones

  • Listar Historial
  • Crear Nuevo Historial
  • Eliminar Historial
