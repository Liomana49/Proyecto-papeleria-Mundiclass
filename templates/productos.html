Gestión de Productos

Esta sección permite gestionar los productos del sistema de inventario y ventas.

Funcionalidades

  • Listar todos los productos
  • Crear nuevos productos
  • Actualizar información de productos existentes
  • Eliminar productos
  • Subir imágenes de productos
  • Ver historial de productos eliminados

Campos de Producto

  • ID: Identificador único del producto
  • Nombre: Nombre del producto
  • Descripción: Descripción detallada del producto
  • Cantidad: Cantidad en stock
  • Valor Unitario: Precio de venta por unidad
  • Valor Mayorista: Precio mayorista (opcional)
  • Categoría ID: ID de la categoría a la que pertenece
  • Imagen URL: URL de la imagen del producto
  • Fecha de Creación: Fecha en que se creó el producto

Ejemplo de Uso

Para crear un nuevo producto, envía una solicitud POST a /productos con los datos requeridos.
