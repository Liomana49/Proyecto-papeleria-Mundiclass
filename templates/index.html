Bienvenido a la API de Inventario y Ventas

Presentación del Proyecto

Esta API asíncrona está diseñada para gestionar de manera eficiente un sistema de inventario y ventas. Utiliza FastAPI para proporcionar una interfaz robusta y escalable, con soporte para operaciones CRUD completas en usuarios, productos, clientes, compras, categorías y un historial de eliminaciones.

Objetivos del Proyecto

  • Proporcionar una API RESTful completa para la gestión de inventarios y ventas
  • Implementar operaciones asíncronas para un rendimiento óptimo
  • Incluir funcionalidades avanzadas como subida de imágenes con Supabase
  • Mantener un historial auditado de todas las eliminaciones
  • Ofrecer documentación automática con Swagger UI y ReDoc
  • Garantizar la integridad de datos con validaciones Pydantic
  • Soportar CORS para integración con frontends

Características Principales

  • Gestión de Usuarios: Crear, leer, actualizar y eliminar usuarios con roles definidos
  • Catálogo de Productos: Manejar inventario con imágenes, precios unitarios y mayoristas
  • Base de Clientes: Mantener información detallada de clientes
  • Registro de Compras: Trackear ventas con cálculos automáticos de totales
  • Organización por Categorías: Clasificar productos con soporte para imágenes
  • Historial de Eliminaciones: Auditoría completa de datos eliminados
  • Subida de Imágenes: Integración con Supabase para almacenamiento en la nube

Tecnologías Utilizadas

  • FastAPI: Framework web asíncrono para Python
  • SQLAlchemy: ORM para interacciones con base de datos
  • PostgreSQL: Base de datos relacional
  • Pydantic: Validación de datos
  • Supabase: Almacenamiento de imágenes en la nube
  • Uvicorn: Servidor ASGI
