Gestión de Usuarios

Esta sección permite gestionar los usuarios del sistema de inventario y ventas.

Funcionalidades

  • Listar todos los usuarios
  • Ver detalles de un usuario específico
  • Crear nuevos usuarios
  • Actualizar información de usuarios existentes
  • Eliminar usuarios
  • Ver historial de usuarios eliminados

Campos de Usuario

  • ID: Identificador único del usuario
  • Nombre: Nombre completo del usuario
  • Cédula: Número de identificación
  • Correo: Dirección de email
  • Rol: Rol del usuario en el sistema
  • Fecha de Creación: Fecha en que se creó el usuario

Ejemplo de Uso

Para crear un nuevo usuario, envía una solicitud POST a /usuarios con los datos requeridos.
