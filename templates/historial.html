Historial de Eliminaciones

Esta sección muestra el historial de todos los elementos eliminados en el sistema de inventario y ventas.

Funcionalidades

  • Listar todos los elementos eliminados
  • Ver detalles de cada eliminación
  • Filtrar por tipo de elemento

Campos del Historial

  • ID: Identificador único del registro de eliminación
  • Tabla: Tabla de la que se eliminó el elemento
  • ID del Elemento: ID del elemento eliminado
  • Datos: Información del elemento eliminado
  • Fecha de Eliminación: Fecha y hora en que se realizó la eliminación

Ejemplo de Uso

Para ver el historial completo, envía una solicitud GET a /historial/eliminados.
