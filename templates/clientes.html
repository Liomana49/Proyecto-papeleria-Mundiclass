Gestión de Clientes

Esta sección permite gestionar los clientes del sistema de inventario y ventas.

Funcionalidades

  • Listar todos los clientes
  • Ver detalles de un cliente específico
  • Crear nuevos clientes
  • Actualizar información de clientes existentes
  • Eliminar clientes
  • Ver historial de clientes eliminados

Campos de Cliente

  • ID: Identificador único del cliente
  • Nombre: Nombre completo del cliente
  • Cédula: Número de identificación
  • Correo: Dirección de email
  • Teléfono: Número de teléfono
  • Dirección: Dirección física
  • Fecha de Creación: Fecha en que se creó el cliente

Ejemplo de Uso

Para crear un nuevo cliente, envía una solicitud POST a /clientes con los datos requeridos.
